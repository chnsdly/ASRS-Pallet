**To compare reusable AS/RS pallets, divide the relevant costs of a defined pallet pool and period by the number of completed loaded trips from that same pool and period.** Include acquisition and replacement, empty returns, inspection and cleaning where applicable, and deduct a defensible remaining value only once. Use the same route, service and accounting rules for each option. The result is an estimate until the inputs have been checked in the actual operation.

This answers a different question from [replacing wood pallets in an AS/RS]({{< relref "resources/customer-cases/wood-to-plastic-asrs-retrofit.md" >}}), which focuses on the change in equipment interfaces. The cost calculation helps compare feasible options; it does not approve a pallet for the route.

## Define one comparable trip {#trip}

Choose a measurable event that represents the work you are buying, for example **one loaded pallet accepted into the automated warehouse and delivered to the agreed outbound handover**. Count that once, even if it uses several conveyors or storage movements. An empty return, a retry after a rejection and an incomplete cycle are not extra completed trips. Another definition can be appropriate, but keep it consistent across options and match the cost period to the trip count.

Specify the route, goods, load mass and distribution, storage temperature and dwell time, expected throughput, and who owns and returns the pallets. A pallet that leaves the site without a reliable return may deliver fewer completed trips to its owner than one in a controlled loop. Use actual tracking records where available; clearly label forecasts as assumptions. When comparing a leased pool, include the contract's fees and obligations rather than inventing a purchase price.

## Put costs on the same basis {#costs}

| Cost or value | What to include in the chosen period |
| --- | --- |
| Pallet assets | Opening pool value, plus purchases including replacements, less supported closing pool value; do not subtract the same resale or residual value twice. |
| Return and handling | The attributable cost of collecting, moving, storing and returning empties, including outsourced fees where relevant. |
| Condition and preparation | Inspection, cleaning, repair or disposal actually required by the operating plan. |
| Route-specific effects | Documented extra handling or downtime attributable to the option, using a consistent valuation method for both alternatives. |
| Other agreed costs | Tracking, financing or transition costs if material and included on a comparable basis. |

Do not add a separate loss charge for an item already captured through purchases and the closing pool value. If a pooling fee already includes return or washing, do not charge it again. For a multi-year investment, use the project's agreed discounting approach; the simple example below is undiscounted. Avoid treating a supplier's quoted lifetime as measured trips under your load and conditions.

## Worked example: one hypothetical pool {#example}

Assume a new pool starts at zero value and runs for one comparison period. The figures below are invented to demonstrate arithmetic; they are not BAOHENG prices, guaranteed lives or expected operating results.

| Input | Assumed amount |
| --- | ---: |
| Initial pallet purchases | $2000 |
| Replacement purchases | $400 |
| Attributable return and handling | $700 |
| Inspection and cleaning | $200 |
| Supported value of pallets remaining at period end | −$100 |
| Completed loaded trips in the same period | 2000 |

Period cost = $2000 + $400 + $700 + $200 − $100 = **$3200**. Cost per completed trip = $3200 ÷ 2000 = **$1.60 per trip**. The ending value represents the whole remaining pool, including any replacements still in service; if it cannot be supported, use zero for a conservative first estimate and state that assumption. No separate damage charge is included because replacements and ending value already account for those assets; other damage-related labour would need its own documented entry.

If the same period cost and closing value were held fixed but only 1600 loaded trips were completed, the result would be $3200 ÷ 1600 = **$2.00 per trip**. This is a sensitivity illustration, not a prediction: lower throughput can also change handling costs and ending value. Recalculate those inputs when they actually change.

## Check the operational alternative before comparing prices {#compare}

1. **Screen the route.** Ask the equipment owner and pallet supplier to review the actual support direction and span, conveyor and pickup contacts, full unit load, temperature and storage time. A cheaper candidate with unverified compatibility is not yet a comparable operating option. See the [conveyor and shuttle interface guide]({{< relref "resources/insights/specify-pallet-for-conveyors-shuttles.md" >}}).
2. **Count what the operation needs.** Check the pool required at the target throughput, including pallets in storage, in transit, awaiting inspection and held as spares. Longer dwell or delayed returns can increase the pool needed even if the number of shipments is unchanged.
3. **Use matched evidence.** Compare actual records for the existing route with a clearly labelled forecast for a new option. Ask who pays each return, cleaning, loss or replacement cost and what a quoted service includes.
4. **Vary uncertain inputs.** Recalculate with lower completed trips, higher return cost and different supported ending value. If the preferred option changes, obtain better records or a relevant supplier quotation before committing.
5. **Validate before rollout.** Agree representative loaded checks and acceptance criteria with the responsible equipment and project owners. Use the [sample testing checklist]({{< relref "resources/insights/asrs-pallet-sample-testing-checklist.md" >}}); a financial calculation cannot substitute for an engineering decision.

## Information to request {#enquiry}

For each candidate, ask for the series, model and configuration, unit price and quantity, applicable drawing, packing and delivery terms, and any sample arrangements. Share the route and load details, estimated pool size and operating period with the supplier; confirm actual return, inspection, cleaning and loss costs with the parties responsible. Pricing, availability and acceptance depend on the actual order and project.

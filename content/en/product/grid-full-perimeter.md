## Best fit

The full-perimeter base provides continuous bottom contact for stable stacking and can improve compatibility with selected conveyors, pallet stops and rack-support arrangements. The grid deck keeps the platform ventilated and easier to inspect.

## Configuration options

- Optional steel tubes to control deck and base deflection
- Anti-slip components, edge details and identification areas where supported
- Custom colors, printing, logo and fleet marking
- Drawing review for conveyor rollers, chain conveyors and support rails

## Engineering note

Reference values are temporary. Final capacity depends on the selected mold, temperature, loading pattern, support span and reinforcement. Always use the approved project specification for purchase and operation.

**比较可重复使用的立体库托盘时，先确定托盘池和核算周期，再用该周期内相关总成本除以同一托盘池实际完成的载货周转次数。** 按实际情况计入采购、替换、空托回收、检验和清洗等费用；有可靠期末价值时只扣减一次。各方案应使用相同路线、服务要求和核算口径。在实际运营数据得到核对前，计算结果只是估算。

本文回答的是经济比较问题；[木托盘替换为塑料托盘的指南]({{< relref "resources/customer-cases/wood-to-plastic-asrs-retrofit.md" >}})重点讨论设备接口变化。成本较低不代表托盘已获准进入立体库路线。

## 先定义一次有效周转 {#trip}

选择一个能记录、且代表实际工作量的事件。例如：**一只载货托盘通过入库接收，并被运送至约定的出库交接点，计为一次有效周转**。中途经过多段输送线或存储动作仍只计一次；空托返回、异常后的重试和未完成的流程不另计有效周转。项目也可采用其他定义，但比较各方案时必须一致，费用和次数应属于同一周期。

记录路线、货物、质量与分布、储存温度和停留时间、预期吞吐量，以及托盘由谁持有和负责回收。离开现场后无法稳定回收的托盘，给持有方带来的有效周转次数可能少于封闭循环。优先使用实际追踪记录，预测值应标明是假设。比较租赁托盘池时，应计入合同规定的费用与责任，不要虚构采购价。

## 用相同口径归集费用 {#costs}

| 成本或价值 | 在选定周期内记录的内容 |
| --- | --- |
| 托盘资产 | 期初托盘池价值，加上采购及替换费用，减去有依据的期末托盘池价值；同一残值或转售价值不得重复扣减。 |
| 回收与搬运 | 空托收集、移动、存放及返回的可归属费用，包括相关外包费用。 |
| 状态与准备 | 运营方案实际需要的检验、清洗、维修或处置费用。 |
| 路线相关影响 | 可归因于该方案的额外搬运或停机费用，并对各方案使用一致的估值方法。 |
| 其他约定费用 | 跟踪、资金或转换费用如有重要影响且口径可比，可一并计入。 |

已通过采购和期末托盘池价值反映的损失，不再另加同一笔损耗费用。如果租赁服务费已包含回收或清洗，也不要重复计费。跨年度投资应采用项目约定的折现方法；下例为不折现的简化计算。供应商提供的寿命信息不能直接当作本项目载荷和工况下的实测周转次数。

## 算例：一个假设托盘池 {#example}

假设核算周期开始时托盘池价值为零，以下数字仅用于演示算法，并非宝恒报价、寿命保证或预计运营结果。

| 项目 | 假设金额 |
| --- | ---: |
| 首批托盘采购 | 2000 美元 |
| 替换托盘采购 | 400 美元 |
| 可归属的回收与搬运 | 700 美元 |
| 检验与清洗 | 200 美元 |
| 周期结束时仍有托盘的有依据价值 | −100 美元 |
| 同周期完成的载货周转 | 2000 次 |

周期成本 = 2000 + 400 + 700 + 200 − 100 = **3200 美元**；单次有效周转成本 = 3200 ÷ 2000 = **1.60 美元/次**。期末价值覆盖所有仍在使用的托盘，包括剩余的替换托盘；若无法支持该估值，可先按零保守估算，并写明假设。例中不另加托盘损坏费用，因为资产损失已体现在替换采购和期末价值中；额外的损坏处置人工则需单独记录。

如果暂时保持同一周期成本和期末价值不变，但有效周转只有 1600 次，则为 3200 ÷ 1600 = **2.00 美元/次**。这只是敏感性演示，不是预测：吞吐量降低也可能改变搬运费用和期末价值，实际变化时应重新计算。

## 比价前先核对运营方案 {#compare}

1. **筛查路线。** 请设备责任方和托盘供应商共同核对实际支撑方向、跨度、输送及取放接触位置、完整货载、温度和储存时间。价格较低但适配性未确认的方案，尚不能视为可直接比较的运营选项。参见[输送线和穿梭车接口指南]({{< relref "resources/insights/specify-pallet-for-conveyors-shuttles.md" >}})。
2. **核算所需托盘池。** 按目标吞吐量检查储存中、运输中、等待检验和备用的托盘数量。即使出货量不变，停留时间变长或回收延迟也可能增加所需数量。
3. **使用同口径依据。** 将现有路线的实际记录与新方案的明确标注预测值比较。确认由谁承担回收、清洗、损失及替换费用，以及报价服务包含什么。
4. **调整不确定的输入。** 分别按较少的有效周转次数、较高的回收费用及不同的有依据期末价值重算。如果优选方案随之改变，决策前应获取更可靠的记录或相应供应商报价。
5. **投入使用前验证。** 与设备和项目责任方约定具有代表性的载货检查及验收标准，参见[样品测试清单]({{< relref "resources/insights/asrs-pallet-sample-testing-checklist.md" >}})。财务计算不能代替工程判断。

## 向供应商提供什么 {#enquiry}

针对每个候选方案，询问系列、型号和配置、单价与数量、适用图纸、包装及交付条件和样品安排。向供应商提供路线、货载、预计托盘池数量及核算周期，并向各责任方核实实际回收、检验、清洗及损失费用。[联系宝恒]({{< relref "contact.md" >}})可讨论候选托盘及报价或样品评估所需资料；价格、供货和项目验收以实际订单与工况为准。

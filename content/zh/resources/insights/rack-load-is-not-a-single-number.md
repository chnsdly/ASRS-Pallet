**比较塑料托盘货架载荷，应同时核对配置、有效载荷及分布、支撑几何、温度、存放时间和数字背后的依据。** 缺少这些条件时，较大的数字并不能证明更适合某一货架或立体库。

本文帮助采购判断哪些供应商资料可以比较、哪些仍需补充，不计算型号承载，也不规定通用挠度限值。设备与采购的整体评审，可结合[立体库托盘选型总指南]({{< relref "resources/insights/asrs-plastic-pallet-selection-guide.md" >}})。

## 1. 先明确报价中的载荷数字表示什么 {#rating}

请供应商说明载荷类型、单位、测试或评估方法，以及质量口径是有效载荷还是还包含其他部分。分别记录有效载荷与包含托盘、包装的整托总质量，并把这些定义保留在报价资料中。

地面支撑下的静载声明、搬运载荷声明和货架支撑声明对应不同情况，不能用假定比例互相换算。同样，报告中的试验载荷也不自动等于仓库允许使用的有效载荷；应确认哪项结果或工作载荷声明支持拟定用途。

[ISO 8611-3:2011](https://www.iso.org/standard/50116.html)涉及已知有效载荷在不同搬运环境下，新平托盘最大工作载荷的确定。这一范围说明，数字需要与载荷和用途一起看，不能把“货架载荷”理解为脱离应用条件的单独属性。

再确认报价对应的“**系列＋型号＋配置＋图纸版本**”，包括材料规格、结构细节，以及适用时的钢管数量、截面、位置和方向。同外形尺寸或另一种增强配置的报告，不能自动作为本次报价配置的依据。更多钢管本身也不能确定更高的允许载荷，相关判断可参考[钢管加强指南]({{< relref "resources/insights/when-steel-reinforcement-adds-value.md" >}})。

## 2. 画清楚实际货架支撑 {#support}

记录托盘放在横梁、导轨、层板还是其他支撑上。在底视图中标出托盘方向、支撑位置、接触宽度及相关的无支撑跨度；纳入支撑杆，并使用货架方或系统方给出的托盘允许放置范围。

**净跨度与支撑中心距是不同尺寸。** 净跨度描述相向支撑面之间的间隔，中心距则在支撑中心线之间测量。在图上明确尺寸起止点，不要只发送一个没有标注的“跨度”数字；支撑形状和实际接触位置仍需评审。

{{< guide-figure src="/images/resources/insights/pallet-interface-checks-zh.svg" alt="托盘底部概念图，展示三条承载线横跨两道支撑，并在支撑内侧面之间标注净跨度" caption="沿用的解释性示意图，用于区分承载线、支撑宽度和净跨度；不是型号图、比例图，也不是经过额定载荷确认的支撑方案。" width="1000" height="680" >}}

确认现有依据是否覆盖该支撑方向和接触方式。整面支撑、两根货架横梁和穿梭车平台，不能因为承托高度相同就视为可互换工况。取货和交接动作还应单独核对[输送线与穿梭车接口]({{< relref "resources/insights/specify-pallet-for-conveyors-shuttles.md" >}})。

## 3. 将货物、温度与时间一起记录 {#conditions}

用底层摆放图或照片说明货物在哪里接触台面。对底脚或集中接触的包装补充接触尺寸、摆放方式、偏心重心及固定方式。总质量相同，不等于接触条件相同；可用[整托货载规格指南]({{< relref "resources/insights/asrs-pallet-unit-load-dimensions.md" >}})整理输入资料。

记录相关存储、搬运阶段的常规和极端温度，以及最长连续带载存放时间，并询问现有依据怎样覆盖这些条件。不能从短时演示直接推断数周的货架存储表现，也不能仅凭材料名称判断冷库适用性。

[英国 HSE《托盘安全》指南](https://www.hse.gov.uk/pubns/pm15.pdf)第 2–3 页，将载荷分布、环境和货架形式列入托盘设计输入。这支持收集上述工况，并不提供宝恒型号承载值，也不规定本项目的通用允许值。

对于变形结果，要区分带载时测得的变化、带载期间是否继续变化，以及卸载并经过明确恢复间隔后仍保留的变形。索取测点、时刻、测量基准、结果与适用限值。只有一张照片或一句“未断裂”，仍未回答这些问题；具体应测哪些项目、采用什么标准，由责任工程方确定。

## 4. 把报告看作某一明确工况的记录 {#report}

索取相关报告或有记录的评估，保留出具方、日期、编号和适用页码。核对试样身份、条件能否关联到报价配置。区分供应商声明、内部测试和第三方报告：出具方身份是依据的一部分，不能替代适用范围核对。

ISO 8611 各部分的用途不同，其公开目录摘要可作如下区分：

| 参考文件 | 在依据中需要确认什么 |
| --- | --- |
| [ISO 8611-1:2025](https://www.iso.org/standard/87543.html) — 试验方法 | 实际采用了哪些相关方法和测试组？ |
| [ISO 8611-2:2025](https://www.iso.org/standard/87544.html) — 性能要求与试验选择 | 哪些要求和选定测试支持本次评估？ |
| [ISO 8611-3:2011](https://www.iso.org/standard/50116.html) — 最大工作载荷 | 工作载荷确定针对哪种已知有效载荷和搬运环境？ |

报价上写有“ISO 8611”，不代表已经明确所用部分、版本、测试和结果，也不等于产品认证。本文使用公开摘要说明区别，没有读取并复述完整标准中的程序或验收阈值。第 1 部分的摘要也指出，针对具体托盘设计的现场试验仍有价值。

可用下表比较报告与拟定用途：

| 评审项目 | 缺少对应关系时的下一步 |
| --- | --- |
| 试验样品与报价配置 | 索取型号、材料、加强配置的关联依据 |
| 支撑与托盘方向 | 索取带尺寸的搭设图 |
| 有效载荷与接触分布 | 索取加载布置和质量定义 |
| 预处理、温度与时长 | 询问哪些依据覆盖拟用条件 |
| 测量、结果与限值 | 索取相关结果页和判定页 |
| 工作载荷结论及排除项 | 请责任评审人写明适用范围 |

托盘上放置重物的照片，可以记录部分搭设情况；照片本身不能说明全部工况、测量和最终工作载荷判断。

## 5. 批准或比较方案前，先写清差距 {#decision}

假设一份报价提供货架载荷及对应的横梁支撑资料，另一份报价提供更高的地面支撑静载数字。下一步应向第二家索取可比较的货架使用依据；直接选更大数字，仍没有解决原问题。这只是比较方法示例，不描述某家供应商或某款产品。

对每个候选方案记录以下一种资料评审结果：

- **已找到适用依据：**责任评审人已明确覆盖拟定上架用途的配置、条件和结论，保留依据编号与限制。
- **需要澄清：**缺少定义、图纸、配置关联或结果，写清问题及应答责任方。
- **需要进一步评估：**已知资料中的工况与拟定用途不同，约定所需工程评审或验证，不自行编造折减系数来填补差距。

这些是资料评审结果，不是自动批准产品。货架/系统方与托盘供应商应确认适用条件及放行流程。样品评估采用批准的方案，明确载荷、支撑、环境、时长、测量和验收标准；不要在运行中的货架上临时组织超载试验。将本项结论与[样品验收清单]({{< relref "resources/insights/asrs-pallet-sample-testing-checklist.md" >}})关联保存。

## 6. 每次询价附上相同的工况表 {#worksheet}

拟用工况填写一次，每份报价重复填写候选方案部分，让供应商回应同一个问题，也让未知条件保持可见。这不是试验方法，也不是已完成的批准记录。

[向宝恒发送工况表]({{< relref "contact.md" >}})、支撑图、货物底层图及候选系列/型号，并附需求数量。我们可根据已有资料讨论候选配置，以及下一步需要的文件或样品评审。在采购记录中固定最终配置、适用条件及哪些变更需要重新评审。

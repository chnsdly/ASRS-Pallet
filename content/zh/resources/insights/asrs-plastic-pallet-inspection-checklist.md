**立体库塑料托盘再次使用前应检查状态，发现破损或无法判断的问题时先隔离，并记录由谁复核、依据什么重新放行。** 对自动化仓库，还需要确认托盘型号及其支撑、取货、导向和检测接口。外形相似，不代表就是项目已经认可的配置。

这篇文章帮助仓库运营、维护和采购人员建立同一份检查记录：先看托盘本体，再查设备接口，最后把异常转成可追踪的处理事项和替换采购资料。

## 1. 在回流和入库环节设置检查点 {#when}

英国 HSE 的[《Pallet safety》PM15 指南](https://www.hse.gov.uk/pubns/pm15.pdf)建议在到货及每次使用时检查托盘，并将破损托盘标识、隔离和移出使用循环。可据此组织现场流程，由项目负责人确定具体检查方法与责任人。

对立体库，适合安排复核的环节包括新托盘收货、空托盘回流，以及进入自动输送前最后一个便于人工检查的工位。碰撞、卡滞、异常交接或工况变化后，也应记录事件和发生位置，不能只把托盘重新放回空托盘堆。

近距离检查应在指定工位进行。托盘卡在设备内部时，由授权人员按现场恢复及隔离程序处理。Interroll 的 [Pallet Drive 操作手册第 2.5 节](https://www.interroll.com/fileadmin/Downloads/User_Manuals/Pallet_Drive/EN_-_Pallet_Drive_Druck_V1.3.pdf)提示运动部件之间的卷入风险，以及故障处理期间防止意外启动的要求；具体操作应遵循现场设备手册。

## 2. 按部位记录塑料托盘的可见状态 {#condition}

按现场安全搬运安排检查可接近的上、下表面。HSE PM15 的塑料托盘条目涉及面板和底部破损、支撑磨损或开裂、永久变形、腔体杂物及环境劣化，并要求进一步咨询制造商。项目仍需制定对应型号的判定依据。

| 检查部位 | 记录哪些现象 | 留下什么资料 |
| --- | --- | --- |
| 面板与边角 | 断格、裂纹、缺料的具体位置 | 顶面全景及带尺寸参照的局部照片 |
| 底梁与底部 | 磨损、分离、破损或形状的永久变化 | 底面照片，标明哪根底梁、哪一侧 |
| 叉孔与取货开口 | 入口边缘破损、通道受阻 | 开口照片及取货方向 |
| 表面与腔体 | 污染、杂物、环境损伤迹象 | 已知的接触环境与清洁状态 |
| 识别信息 | 型号、批次、资产编号及不确定项 | 标识照片与已认可图纸编号 |

无法依据已确认条件判断时，保持待复核状态。外观不能直接证明剩余承载能力。怀疑材料劣化时，应向制造商核实；HSE 将表面白色粉状沉积列为拒用迹象。

## 3. 把检查结果对应到设备接口 {#interfaces}

以下是项目复核问题，具体基准面和尺寸由设备供应商确认，不是通用报废限值。

| 接口 | 需要托盘与设备双方确认的问题 |
| --- | --- |
| 滚筒输送线 | 底梁接触是否符合已认可的方向和支撑方式？ |
| 链条移载 | 设计接触区域是否完整、畅通？ |
| 穿梭车或堆垛机取货 | 取货开口和底面是否仍与认可图纸一致？ |
| 货架存储位 | 是否为对应支撑方向、跨度和配置的托盘？ |
| 导轨、挡停与传感器 | 用于定位、接触和识别的部位是否仍可用？ |

一条可追踪的异常记录可以写成：“托盘 P-017，底梁 B，边角碰撞后在 T-04 移载点出现刮擦，附底面照片，已隔离待复核。”这条记录明确了对象、位置和下一步；只写“托盘运行不顺”则难以安排处理。这里是记录示例，不是客户事故报告。

如果多块托盘在同一个交接点出现相似磨痕，应把设备接口和搬运方式一起纳入复核。仅更换托盘，未必解释了重复异常的原因。可参考[输送线与穿梭车托盘选型指南]({{< relref "resources/insights/specify-pallet-for-conveyors-shuttles.md" >}})收集接口图纸和设备信息。

## 4. 明确隔离、放行与更换的责任 {#decision}

现场状态应清楚可辨，避免待处理托盘被当成可用库存重新上线。

- **隔离待复核：**标识托盘，阻止重新进入路线，指定复核人，记录问题和照片。
- **确认放行：**记录判定依据、复核结果、批准人和日期。完成清洁或空载通过入口检测，本身不能说明结构问题或带载运行疑问已经解决。
- **更换或退出使用：**记录原因，防止误用，并按托盘所有者的处置或回收安排执行。

如考虑维修，应先取得制造商或托盘责任方认可的方法和重新投入使用的条件。不要为了“能通过”而自行削切底梁、钻孔或改变加强件。配置一旦改变，就需要重新确认适配范围。

本文不规定统一的裂纹长度、磨损深度或使用年限。针对具体托盘和设备，应约定可测量的标准，写清测量位置、状态与方法。一份检查表还需要对应的决策责任人，才能形成处理闭环。

每块托盘或每个可识别问题单独记录。未知信息标注为**待确认**，照片与记录一起保存。

| 记录项目 | 填写内容 |
| --- | --- |
| 对象信息 | 资产或批次编号、型号、图纸版本、检查人及日期 |
| 使用工况 | 工位、运行方向、载荷、支撑方式与温度 |
| 问题描述 | 受影响部位、可见状态、事件经过与照片编号 |
| 判定依据 | 制造商或设备文件、版本及对应条目 |
| 处理安排 | 隔离位置、复核人、下一步及计划复核日期 |
| 最终结果 | 放行、继续隔离或退出使用；批准人与支持资料 |

## 常见问题 {#faq}

### 塑料托盘有划痕，还能进立体库吗？

仅凭“有划痕”无法判断。先记录位置和状态，再对照制造商认可的判定条件及相关设备要求。无法确认影响时，应保持隔离待复核。

### 通过入口检测，就说明可以上货架吗？

入口检测结果只对应该工位实际执行的检查。需要明确它测量了什么，不能由此推定未检测的底梁状态、带载货架性能或其他取货接口已经合格。

### 立体库塑料托盘多久换一次？

应结合制造商说明、实际使用条件和检查结果决定，本文不设统一年限。如有使用时间或循环次数记录，可与状态、碰撞和异常历史一起用于复核。

### 替换托盘只要长宽一样就行吗？

长宽只是部分条件。还要确认底部结构、取货间隙、材料和加强配置、整托货物外廓及设备要求。配置变化可通过双方约定的[样品验收计划]({{< relref "resources/insights/asrs-pallet-sample-testing-checklist.md" >}})验证。

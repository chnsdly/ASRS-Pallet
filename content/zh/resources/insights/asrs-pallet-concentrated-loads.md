**当货物通过脚座、桶底边缘或其他有限区域接触托盘时，应记录完整货载的实际接触位置，并请托盘供应商和设备责任方复核具体组合。** 不同载荷分布或支撑条件下的目录数字，不能单独证明拟议用途可行。货架支撑、货物固定、温度和时间同样需要核对。

[货架载荷比较指南]({{< relref "resources/insights/rack-load-is-not-a-single-number.md" >}})侧重如何阅读承载数字和报告；本文侧重另一项采购工作：描述非均匀载荷，并复核拟议的分载垫板。

## 1. 描述实际接触 {#contact}

拍摄货物底部，以托盘上标记的参考边绘制俯视图。记录脚座、底部导轨、桶底边缘或其他接触区域的数量、形状、尺寸和位置，区分实测接触与估计值。标出凸出物、尖锐边缘、可能的超出托盘范围及运行方向。桶底边缘、带脚座的容器和覆盖面板的纸箱，受力位置未必相同。

记录最大工况下的货物总质量，包括内容物和包装；另行记录完整移动质量，包括托盘及中间垫层。标出重心及可能的变化。除非责任工程人员已确定分配方式，不要假设四个脚座各承担四分之一重量。

[弗吉尼亚理工大学包装与单元载荷设计中心](https://www.unitload.vt.edu/education/white-papers/5-wp-load-carrying-capacity-of-pallets.html)区分点、线等载荷方式，并强调同时确定加载和支撑条件；该资料不提供宝恒具体配置的额定值。

## 2. 对照每一种支撑工况 {#support}

| 复核项目 | 需要提供的信息 |
| --- | --- |
| 托盘 | 系列、型号、图纸版本、面板、底部结构、材料和可能的增强配置。 |
| 货物接触 | 接触示意及尺寸、货物质量、偏载和内容物或位置可能的变化。 |
| 货架 | 支撑方向、位置、接触宽度和净跨度；允许的位置范围由系统供应商确定。 |
| 搬运 | 货叉或穿梭车的接触和动作、输送转接、完整单元尺寸及总移动质量。 |
| 环境 | 温度范围、最长载货存储时间以及相关清洗或暴露条件。 |

询问供应商哪些依据同时覆盖相同托盘配置、载荷方式和支撑。如果报告采用均匀分布载荷，应请求针对实际接触方式的评估，不要自行套用折减系数。平整地面、两根横梁和穿梭车平台是不同支撑条件。用[完整货载尺寸指南]({{< relref "resources/insights/asrs-pallet-unit-load-dimensions.md" >}})记录组装后的单元。

## 3. 将分载垫板视为新组合 {#layer}

项目可能考虑用刚性板、垫板或框架改变货物向托盘传递载荷的方式。效果取决于垫层的刚度、形状、接触和支撑。增加垫层不自动意味着载荷均匀，也不自动证明托盘适用。应请货物责任方、托盘供应商和系统方共同复核完整组合，包括货物对垫层及垫层对托盘的作用。

记录垫层尺寸、质量、材料、方向及固定方式，以及上下两面的接触情况。检查对总高度、总质量、重心、传感器、取放、摩擦和存储要求的影响。如果垫层发生位移、超出边缘、遮挡必要接口或证据不足，应保持方案待定，直到责任方约定合适的评估。本文不指定垫板厚度，也不承诺承载提升。

## 4. 比较依据并约定试验 {#evidence}

对每份报价保留测试或评估编号，核对托盘配置、载荷方式、支撑几何、温度、持续时间、观察结果及排除条件。区分供应商声明与适用的测试或工程评估。条件不一致时，较大的数字无法解决比较问题。

代表性样品检查前，项目方和设备供应商应约定实际货物或适当代表载荷、接触位置、路线、存储支撑、环境条件、观察项目及验收标准，并记录样品身份、图纸和结果。不要自行进行超载试验或进入运行设备；遵守现场批准的隔离和试验程序。短期试验本身不能证明长期货架性能。参见[样品验收清单]({{< relref "resources/insights/asrs-pallet-sample-testing-checklist.md" >}})。

## 准备询价 {#enquiry}

[联系宝恒]({{< relref "contact.md" >}})时提供货物底部示意图和照片、最大货物质量和完整质量、托盘方向、货架支撑图、温度及存储时间。说明拟议垫层和所需数量。我们可讨论候选配置及可提供的依据或样品资料；项目批准由责任方确定。
